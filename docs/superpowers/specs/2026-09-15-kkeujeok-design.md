# 끄적임 탭 — 설계 문서

- 작성일: 2026-09-15
- 대상 사용자: 증권/주식 유튜버 (비개발자), 기존 "증권 뉴스레터 도우미" 사용자
- 목적: 하루 동안 카톡 "나와의 채팅"에 태그를 붙여 모아 둔 링크·메모를 붙여넣으면, 태그별로 정리하고 기사 제목·요약으로 "사실" 줄을 채운 **3줄 공식 초안**(사실 / 해석 / 내 생각)을 만들어 준다.
- 배경: 매일 받는 개인 시황 뉴스레터(항목마다 링크 1개 + 짧은 코멘트) 방식을 따라 하기 위한 자료정리 루틴의 앱 버전. 루틴 안내 페이지: https://claude.ai/artifact/MbVeww4sXaybFKLfTqTSoH

## 1. 범위

### 하는 것
- 나와의 채팅에서 복사한 텍스트를 태그별로 나눈다.
- 링크를 서버에서 열어 기사 제목·요약(og 메타)을 가져온다.
- 태그 순서대로 번호를 매긴 3줄 공식 초안을 만들고, 복사/카톡 보내기를 제공한다.

### 하지 않는 것 (이번 버전)
- **AI/LLM 사용 안 함.** "해석"·"내 생각" 줄은 항상 빈칸. (기존 설계의 "AI 미사용, 운영비 0원" 원칙 유지 — 사용자 확정)
- 추적 노트 자동 이어쓰기 (`#노트`는 초안에서 제외만 한다)
- '추천' 탭에서 체크한 리포트 끌어오기
- 라벨(`사실:` 등) 지우기 버튼

## 2. 화면

하단 탭을 4개로 늘린다: **추천 · 뉴스레터 · 끄적임 · 관심종목**. 새 경로 `/kkeujeok`.

한 화면에서 위에서 아래로:

1. **붙여넣기 칸** + **[정리하기]** 버튼
2. **태그별 묶음 목록**
   - 묶음 순서: 한마디 → 밤 → 장 → 테마 → 종목 → 볼것 → 태그 없음
   - 각 항목: 체크박스(기본 체크) · 메모 · 링크 도메인 · 가져온 기사 제목(있으면)
   - 기사 정보를 가져오는 동안 "기사 정보 가져오는 중" 표시. 실패해도 항목은 그대로 남는다.
   - `#노트` 메시지는 목록·초안 모두에서 제외
3. **[초안 만들기]** → 편집 가능한 초안 텍스트 칸
4. **[전체 복사] [카톡으로 보내기]** — 뉴스레터 탭과 같은 동작. 두 화면이 공유하도록 기존 코드를 `components/ShareButtons.tsx` 컴포넌트로 옮긴다.

붙여넣은 원문과 초안은 `localStorage`(기존 `lib/storage.ts`의 `snl:` 접두어 방식)에 저장해 탭을 오가도 유지한다.

빈 상태·오류 문구:
- 붙여넣은 내용에서 항목이 하나도 안 나오면: "정리할 메시지를 찾지 못했습니다. 나와의 채팅에서 복사한 내용을 그대로 붙여넣으세요."
- 체크된 항목이 없으면 [초안 만들기] 비활성화

## 3. 붙여넣기 파싱 — `lib/memoParse.ts`

입력: 붙여넣은 텍스트. 출력: `MemoItem[]`

```ts
type MemoTag = "한마디" | "밤" | "장" | "테마" | "종목" | "볼것" | "노트";
interface MemoItem {
  tag: MemoTag | null;   // null = 태그 없음
  memo: string;          // 태그·URL·카톡 접두어를 뺀 나머지, 공백 정리
  url?: string;          // 메시지의 첫 번째 URL
}
```

규칙:
1. **메시지 경계 = 카톡 접두어가 있는 줄.** 인식하는 접두어:
   - 모바일 복사: `[이름] [오전 7:31] 내용`
   - PC 내보내기: `2026. 9. 15. 오전 7:31, 이름 : 내용`
2. **날짜 구분선은 버린다.** 예: `--------------- 2026년 9월 15일 화요일 ---------------`, `2026년 9월 15일 화요일`
3. **접두어 없는 줄은 바로 위 메시지의 이어지는 줄**로 붙인다. 붙여넣은 텍스트 전체에 접두어가 하나도 없으면(직접 쓴 메모 등) **줄 하나를 메시지 하나**로 본다.
4. **태그:** 메시지 안의 첫 번째 인식 태그(`#한마디 #밤 #장 #테마 #종목 #볼것 #노트`)를 쓰고 메모에서 지운다. 그 외 `#단어`(예: `#쇼츠`)는 일반 글자로 남긴다.
5. **URL:** `http://`·`https://`로 시작하는 첫 번째 URL. 두 번째 이후 URL은 메모에 글자로 남긴다.
6. **빈 메시지 제외:** 태그·URL을 빼고 메모도 URL도 없으면 버린다.
7. **중복 링크:** 같은 URL이 두 번 나오면 먼저 나온 항목만 남긴다.

## 4. 기사 정보 가져오기

### API — `app/api/linkinfo/route.ts`
- `POST { urls: string[] }` → `{ [url]: { title?: string; description?: string } }`
- 한 번에 최대 30개. 초과분은 무시.
- `http`/`https` 이외의 URL, `localhost`, IP 주소로 된 링크는 무시(서버가 내부 주소를 열지 않도록).

### 가져오기 — `lib/linkInfo.ts`
- 서버에서 `fetch` (User-Agent 지정), **링크당 8초 타임아웃**, 모두 동시에.
- 추출: `og:title`(없으면 `<title>`), `og:description`. HTML 엔티티(`&quot;` 등) 해제.
- 인코딩: 응답 헤더나 `<meta charset>`이 EUC-KR이면 `TextDecoder("euc-kr")`로 해석 (기존 `lib/sources/naver.ts`와 같은 방식).
- **건너뛰는 사이트** (열지 않음): `finance.naver.com`, `markets.hankyung.com`, `investing.com`(하위 도메인 포함), `truthsocial.com`.
  - 2026-09-15 실측: 사이트 이름("Npay 증권", "Truth Social")만 오거나 403 차단.
  - 한계: 새로 이런 사이트가 나오면 목록에 직접 추가해야 함. 코드에 `ponytail:` 주석으로 명시.
- 실패(네트워크 오류, 타임아웃, 200 아님)는 해당 링크만 정보 없음으로 처리하고 나머지는 계속.

실측으로 확인된 동작 (2026-09-15):

| 링크 | 결과 |
|---|---|
| 네이버 뉴스, 이코노빌, 인사이트, 뷰어스 | 제목 + 요약 정상 |
| X(트위터) | 제목 "이름 on X", 요약 = 트윗 본문 |
| YouTube | 영상 제목 |
| 인베스팅 | 403 |
| 한경 마켓맵 | og 없음, title "코스피 마켓맵 \| 한국경제" |
| 네이버 금융 종목, 트루스소셜 | 사이트 이름뿐 |

## 5. 초안 만들기 — `lib/kkeujeok.ts`

입력: 날짜 라벨, 체크된 `MemoItem[]`, 링크 정보 맵. 출력: 텍스트.

```
오늘의 끄적임 · 2026년 9월 15일

1. https://www.insight.co.kr/news/549347
사실: ‘중국산 로봇’ 철퇴 준비중인 미국, 현대차그룹의 ‘호재’로 떠올랐다
해석: 
내 생각: 

2. https://markets.hankyung.com/marketmap/kospi
사실: 코스피 +6.8% 개인 7조 매도
해석: 
내 생각: 
```

- 번호는 태그 순서(한마디 → 밤 → 장 → 테마 → 종목 → 볼것 → 태그 없음)대로 이어서 매긴다. 같은 태그 안에서는 붙여넣은 순서. 소제목 없음.
- URL이 없는 항목은 번호 줄에 URL 대신 아무것도 쓰지 않는다 (`3.`).
- **사실 줄 조립:**
  1. 메모가 있으면 메모
  2. 기사 제목이 있으면: 메모가 있을 땐 뒤에 `(기사: 제목)`, 없을 땐 제목만
  3. 기사 요약이 있고 제목과 다르면 첫 문장을 뒤에 덧붙임
  4. 아무것도 없으면 `사실: ` 빈칸
